constexpr Error pf1550::Validate ( const Config &  config)
constexprnoexcept

Check a configuration without touching the chip.

Fails with InvalidArgument for an unset or insane Limits, a value off the data sheet grid, a reserved code or a value that is not an enumerator; with OutOfLimits for a valid value outside Limits; with ReadOnlyRail for a buck voltage on SW3 or on a buck not declared Dvs::Enabled; with Unsafe for a safety downgrade without its acknowledgement.

Parameters
configThe configuration.
Returns
Error::Ok or the first failure.
