Detailed Description

Public types of the PF1550 driver: errors, Result<T>, enumerations, units, status and interrupt types.

Copyright
Copyright (c) 2026 The driver-pf1550 authors. SPDX-License-Identifier: MIT

Everything here is plain data with no platform dependency. The configuration lives in pf1550_config.hpp, the register codecs in pf1550_codec.hpp. Enumerator values equal the register codes of the data sheet tables (section 12) wherever the table is contiguous, and every enumeration that a caller can hand in has an EnumLast specialisation for IsEnumerator().
