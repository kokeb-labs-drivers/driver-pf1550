# PF1550 Driver API reference {#mainpage}

The classes, types and registers of the PF1550 driver, generated from the headers in `inc/`.

Start with pf1550::PF1550, the driver, and pf1550::I2cInterface, the base of the port you write. Errors are
pf1550::Error inside pf1550::Result; the configuration is pf1550::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">PF1550 Driver
documentation</a>.
