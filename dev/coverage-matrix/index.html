Coverage matrix¶

One row per datasheet (Rev. 7) parameter: register, bit field, interrupt source, state, electrical or timing parameter, pin, OTP value. Each row names the driver API, the model behaviour and the test suite with its files; the status says whether the behaviour is covered. The source is coverage-matrix.csv; this page is generated from it by python3 tools/coverage_matrix.py write, and python3 tools/coverage_matrix.py check verifies the totals against Coverage.

Totals: 1090 rows; OK 729, INFO 360, TODO 1.

The test suite ids (T01 to T28) name groups of tests; the files column lists where they live. A suite is not one test case: it is the set of cases in those files that exercise the behaviour.
