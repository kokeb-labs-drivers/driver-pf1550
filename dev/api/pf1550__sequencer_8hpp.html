Detailed Description

The regulator power-up and power-down sequencer of the PF1550 as pure constexpr data: the pre-programmed start-up options (Table 85), the sequencer timing (Table 84) and the power-down order (section 10.7).

The power-up order is fixed by OTP and cannot be read back over I2C (the OTP image is not documented in the public data sheet), so the driver reports it only for the pre-programmed options A1 to A9 that Table 85 lists, selected by the OTP_FLAVOR byte that ReadVariant() returns. The power-down order is a set of read/write registers, *_PWRDN_SEQ, that the application may change in a system-on state.

Model choices where the data sheet is silent (each one has a knob in the test model):

  • the slot of a regulator with PWRUP_SEQ = n starts (n - 1) slots after the first one, and a PWRUP_SEQ of 0 starts in the first slot (ambiguity C54);
  • regulators with equal power-down order turn off together (C55);
  • with some orders non-zero, a regulator with order 0 turns off last (C56).
