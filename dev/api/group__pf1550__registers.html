enum class pf1550::reg::Access : uint8_t
strong

Access class of a register: what the driver is allowed to do with it.

Enumerator
ReadOnly 

Identity, state, SENSE, OK and SNS registers: never written.

Status 

Interrupt status (write 1 clears reported bits only): written by the service only.

Mask 

Interrupt mask: read-modify-write of defined bits.

OtpCfg 

Loaded from OTP at start-up, then read/write: typed setter with read-back.

Cfg 

Ordinary configuration: typed setter with read-back.

Command 

PWRCTRL3 (GOTO_SHIP, GOTO_CORE_OFF): written only by the shutdown calls; the typed setter refuses it.

Never 

Documented, but no call writes it (reserved, keys, SW3 voltages, evaluation bits).
