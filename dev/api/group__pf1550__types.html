◆ Error

enum class pf1550::Error : uint8_t
strong

Why a call failed. Every call of the driver returns one of these in its Result.

Values 0 to 9 are the shared base set; chip-specific values start at 16. [[nodiscard]] on the type: a function that returns a bare Error cannot have it ignored either (KB-CPP20-037).

Enumerator
Ok 

The call succeeded.

NotInitialized 

EnsureInitialized() has not succeeded yet.

InvalidArgument 

A value is not on the data sheet grid, is reserved or not an enumerator; nothing was sent.

Bus 

A port hook returned false.

Timeout 

A wait for the chip (a DVS step) did not end in the allowed time.

DeviceIdMismatch 

DEVICE_ID did not read 0x7C: wrong chip, no chip or a wiring fault.

Crc 

Not returned by this driver (I2C transfers carry no CRC).

Busy 

Not returned by this driver (the chip has no busy state).

DeviceFault 

Not returned by this driver (faults are reported as ChargerFault).

Unsupported 

The optional port hook this call needs is absent.

OutOfLimits 

A valid value outside the caller's Limits; nothing was sent.

ReadOnlyRail 

SW3, or SW1 or SW2 not declared in DVS mode: its voltage is not written.

Unsafe 

A safety downgrade without its acknowledgement; nothing was sent.

Refused 

A precondition of a dangerous call is not met (state, VBUS, ONKEY).

ChargerFault 

The charger reports a fault state; charging is not enabled.

VerifyFailed 

A register read back differently from what was just written.

NoDevice 

Nothing acknowledged the address: no chip, or it is unpowered.

DeviceReset 

The chip reset itself (a register the driver changed is back at its start-up value): run EnsureInitialized() and Configure().
