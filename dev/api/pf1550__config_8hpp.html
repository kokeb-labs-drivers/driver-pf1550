Detailed Description

PF1550 configuration: the application's Limits, its explicit acknowledgements, the typed configuration of every block and Validate().

The chip is a power supply: a wrong byte can overcharge a cell or overvolt a processor. The driver therefore has no public raw register write. Everything is written through the typed values below, after Validate() has checked them against the data sheet grids and against Limits, the application's own description of what its battery, supply and loads tolerate. Limits has no defaults: an unset limit is rejected. A safety downgrade (no charge timer, thermistor ignored, no battery overcurrent protection, a hard-reset path changed) is accepted only with the matching flag of Acknowledgements, so that it is visible in the application's source.
