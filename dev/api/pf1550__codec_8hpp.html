Detailed Description

Register codecs of the PF1550: voltage and current grids of the data sheet tables, as constexpr functions that are total only over the documented codes.

Copyright (c) 2026 The driver-pf1550 authors. SPDX-License-Identifier: MIT

Every encoder returns InvalidArgument for a value that is off the grid or in a code the data sheet labels Reserved; every decoder returns InvalidArgument for a reserved code. The anchors of each table are proved with static_assert at the end of the file (KB-CPP20-012).
